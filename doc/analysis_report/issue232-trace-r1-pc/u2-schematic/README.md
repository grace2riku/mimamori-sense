## 確定した接続

```text
VCC5（TP3） ┬─ R16 10Ω ─ U2-29 VDD  ─ C31-2（C31-1はGND）
            ├─ R17 10kΩ ─ U2-28 EN   （R17-1がEN側）
            └─ Q1 ─ TFT_NODE1 ─ L2/D2 ─ Q2 ─ AVDD（TP4）

J1-6 RESET_L ┬─ J2-7 → LCD RESET
             └─ J3-4 → タッチ RESET

GND（TP9/TP10） ─ R35 0Ω ─ TFT_PGND（TP12〜TP16）
```

- U2の制御電源VDDは5V由来。TP8の3.3VはU2 VDDではない。
- U2 ENはR17によってVCC5へ引き上げられる。ENネットの端子はR17-1とU2-28のみ。
- RESET_L/RESET#ネットはJ1-6、J2-7、J3-4。U2 ENとは別ネット。
- U2-30 PGはQ1ゲート、U2-3 DELBはR25を介してQ2ゲートへつながる。TP3はQ1前、TP4はQ2後であり、TP3とTP4だけでは途中段の状態を区別できない。
- U1のBLENはPWMI（U1-5）につながり、U1-6 ENはVCC5につながる。前段でBLENを「バックライト制御」とした説明はこのPWM制御を指す。U2 ENではない。

したがって既存のLCD RESET操作だけでU2 ENをLow/Highに切り替えることはできない。
ソフトのRESET操作は `e2studio_CPU0/src/port/glcdc_port.c:316,319,322`。
この配線結果は、ソフトによる負荷・信号の立上りが電源に間接影響する可能性を除外しない。

## 測定点の優先度とアクセス条件

| 優先 | 測る点（GND基準） | 目的 | アクセス |
|---|---|---|---|
| 1 | C31-2 = U2-29 VDD = R16-1 | R16後の実入力が正常／白で低下するか | C31は裏面1210。U2の細い端子より候補に適するが、現在の固定状態ではアクセス困難 |
| 2 | R17-1 = U2-28 EN | ENが引き上がっているか | R17は裏面0402。専用TPなし。表側の代替TPはない |
| 表側で追加可能 | TP12〜TP16のいずれかとTP9/TP10の電位差 | TFT_PGNDとGNDの電位差の有無 | 下端の未使用5点。正常ならほぼ0Vを期待 |

VDDネットはU2-29/R16-1/C31-2、ENネットはU2-28/R17-1だけ。
製造データの部品配置はすべてbottom。既存の露出した表側TPにVDD/ENの同一ネットはない。
表側の銅箔や小さいビアへの接触、LCDの下に隠れた箇所を新しい測定点として案内しない。
裏面を使うには一度固定を外すか、電源OFFで適切に測定線を取り付ける必要がある。
その作業は未実施・今回の測定依頼に含めない。

## 表側だけで行う場合の最小確認

前の写真IMG_7505と同じ向きで、下端10点の左から1/3/5/7/9番が
TP15/TP14/TP13/TP16/TP12（すべてTFT_PGND）。左から9番のTP12を使用できる。
黒を左辺TP9またはTP10（GND）、赤を下端左から9番TP12へ当て、直流電圧を測る。
正常／白でともにほぼ0Vなら、測定時点の大きなGND電位差は見られない。
非ゼロでも直ちにR35断線とはせず、接触と基準点を確認する。
この結果が0VでもU2のVDD/ENが正常だった証拠にはならない。
通電中に抵抗・導通モードを使用しない。

## 現時点の診断

実測の正常時AVDD=9.73V、VGH=18.46V、VGL=-6.16V、VCOM=3.629Vは、
回路図に記載された設計範囲9.4〜9.8V、17〜19V、-6.6〜-5.4V、3.4〜3.8V内。
白の出力低下は明確だが、EN/VDD低下、保護停止、途中のQ1/Q2、負荷異常は未分離。

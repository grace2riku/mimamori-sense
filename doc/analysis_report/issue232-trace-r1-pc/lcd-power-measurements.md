ユーザー報告: 1回目正常、2回目白。表側のTP対応を案内した後の測定。
給電元・測定までの秒数・測定中の表示変化は今回の報告には明記されていない。
過去のソフトログと同一起動であるとは扱わない。白率の判定試験ではない。

## 確認できた差

測定時点のTP3/TP8は正常時とほぼ同値なのに、白ではLCD駆動電源4系統が大幅に低下した。
正常時の値を仕様上の保証範囲と断定せず、同じ基板の正常表示時との比較として扱う。
特にVGH/VGL/VCOMはほぼ消失しており、白の状態を説明する具体的な電源異常を初めて観測した。
GLCDCレジスタ・CPU側バッファ標本が正常でも、LCD駆動電源の成立を保証しないという
前段の未観測点を埋める結果。ただし今回のソフトログ同時取得はない。

## 仕様と仮説

Renesas Parallel Graphics Expansion Board 1 manual Rev.1.01、表1/2および4.5節で
TPの対応とU2=ISL78010によるLCD電源生成を確認済み。
ISL78010 FN6501 Rev.2.00 p.15のStart-Up Sequence / Fault Protectionには、異常検出時に
停止を保持し、EN切替または入力電源再投入で解除する動作が記載される。

- 基板資料: https://www.renesas.com/en/document/mat/parallel-graphics-expansion-board-1-v1-users-manual
- IC資料: https://www.renesas.com/en/document/dst/isl78010-datasheet
- 保存資料: `e2studio_CPU0/Debug/issue230/parallel-graphics-board-manual.pdf`、`isl78010-datasheet.pdf`

今回の値はU2周辺の起動不成立／保護停止と整合するが、そのどちらか・保護種別は未確定。
EN、U2端子での入力、起動瞬間の波形、出力負荷を未測定なので、EN無効、負荷異常、
入力過渡変動などの区別はできない。AVDD=2.560Vの残留値から特定の経路・状態を断定しない。
定常4.66/4.67Vが同じことから、起動瞬間の電圧低下を否定してはいけない。
RTC保持・200ms待ちとの因果や、ソフト起動順序の関与も未確定であり、部品故障とも断定しない。

## 次の調査

優先対象をLCD電源U2周辺の起動・停止条件へ移す。回路図でU2のVIN/VDD/ENと
RESET_Lの接続関係を確認し、テスターで接触可能な測定点を確定してから次の取得を依頼する。
LCD RESETと電源IC ENを同一と仮定したソフト修正、EN端子の短絡、追加待ち値探索は行わない。
TP3〜TP8の同じ測定を多数回繰り返す必要は現段階ではない。

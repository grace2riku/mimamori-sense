# 要求事項

マルチコアプロジェクト(e2studio, e2studio_CPU0, e2studio_CPU1)のFSP設定を確認してください。

## 要求事項詳細

1. e2studio_CPU0, e2studio_CPU1のFSP設定でプロジェクト新規作成時から変更しているFSP設定を一覧表にしてください。
   - 設定メニューの場所
   - 設定変更内容
   - 設定変更理由
   - FSP出力コード
   - FSPを利用しているところ

2. e2studio_CPU0とquickstart(reference_projects/quickstart_ek_ra8p1_ep)のFSP設定の違いを比較し差分を明らかにしてください。

3. 将来的にquickstartのコードをe2studio_CPU0に移植したいと考えています。FSP設定変更に注目し、移植のステップを提案してください。

## 出力先
解析結果は `doc/analysis_report/multicore_fsp_config_analysis.md` に保存してください。
